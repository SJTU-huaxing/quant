# 本地策略观测站

在项目目录运行：

```powershell
conda activate quant
python -I scripts/dashboard.py
```

浏览器访问 **http://127.0.0.1:8765**。更换端口可以用 `--port 8766`；只能监听本机环回地址。
网页每 5 秒更新，关闭浏览器不会停止正在运行的行情扫描和模拟风控。
停止网页服务可在启动它的终端按 Ctrl+C；这不会停止另外运行的模拟 worker。

网页包括：

- 1×、2×、3× 三组独立 50 USDT 虚拟账户；点击账户卡片切换风险、持仓和平仓详情。
- 净值曲线支持最近 1 / 6 / 24 小时与全部记录；图上的点可查看采样时间及净值。
- 市场方向、币池趋势分布、模型 / 币种 / 候选状态筛选；详情说明评分依据和阻止原因。
- Codex 复核理由、每组模拟执行或拒绝结果，以及带退出原因的平仓记录。
- 小时策略的独立留出期与最近 7 日诊断对照。
- 扫描、风控和复核时间提示。服务断开或报价过期时明确显示旧数据状态，缺失值显示为未知。

全部时间以北京时间（Asia/Shanghai）显示。主网公开行情用于信号，测试网报价用于本地模拟成交；页面不是 Binance 账户页面，真实交易所订单为 0。规则评分不是盈利概率，三组本金不可相加。

## 持续运行

行情和风险进程独立运行，网页服务不会替它们启动或改变交易状态：

```powershell
python -I scripts/tactical_lab.py scan-watch
python -I scripts/tactical_lab.py paper-watch
python -I scripts/strategy_lab.py watch
```

每条命令使用各自终端；已有同类进程时不要重复启动。暂停短线 worker 的方法见 [短线实验说明](tactical_lab.md)。

2026-09-15 用户已将授权更新为**每 10 分钟 Codex 复核，并允许新的模拟开仓**。当前任务已设置对应的定期检查；这个计划保存在 Codex 应用中，不会随 Git 仓库复制到其他设备。保持电脑、网络与 Codex 应用运行，计划才能访问本地项目。网页仅展示计划频率及最近一次实际复核记录，不能据此保证下一次任务的准确执行时间；超过 20 分钟没有新复核会提示检查。

没有新的有效复核、没有合格信号，或者数据/风控失效时不新增模拟仓位。所有实际账户操作及主网交易均保持关闭。收益达标仍需更多样本验证，不能因为一次短期盈利而上线主网。

## 数据与实现

前端位于 `web/`，服务位于 `src/quant_binance/dashboard.py`。只使用 Python 标准库和本地前端资源，无外部字体、脚本 CDN 或账户依赖。服务以固定路由提供 HTML、CSS、JS、健康状态和聚合 JSON，不提供目录索引、任意文件下载或交易/参数修改接口，并校验 Host、Origin 与跨站请求。

聚合数据只来自 `reports/tactical/signals.json`、`paper_status.json`、`reports/strategy_lab/latest.json` 和经过实验 ID 校验的虚拟账本。不会打开 dotenv 或调用账户配置加载器。

图表历史独立保存于 `data/dashboard/history.sqlite3`，按实验与杠杆隔离、去重并保留最近 30 天实测采样。只录入报告新鲜且估值可用的净值；图表另外显示已有账本的初始本金与稀疏小时快照。超过 60 秒的采样缺口不连线，早期没有逐秒数据的区间不会伪造。密集序列展示时保留分桶极值，因此不会通过均值采样抹掉回撤；这张图仍不替代账本中的完整风险统计。

数据、报告、日志和显示历史均被 Git 忽略，仅上传代码、公开模板、说明和离线测试。

网页现分为“因子与策略”与“趋势跟踪”两个工作区。因子研究详情与单位解释见 [研究说明](factor_lab.md)；服务额外读取固定公开报告 `reports/factor_lab/latest.json`，不增加写入交易参数或下单的接口。
