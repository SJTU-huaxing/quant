# 短线山寨币：本轮复核、杠杆对照和持续模拟

这是比原有小时策略更积极的独立实验：扫描短期波动较大的 USDT 永续合约，结合 5 分钟和 15 分钟指标形成候选，再由本轮 Codex 分析决定是否允许一次模拟开仓。**行情来源为主网公开接口，成交使用测试网公开报价进行本地模拟，真实订单始终为 0。**

不读取 dotenv，不登录账户，不修改杠杆、保证金、代理或系统网络。原有小时策略采集器继续运行，作为另一组独立实验。其虚拟资金与本实验不能相加，也不代表增加了用户授权的真实本金。

## 指标与币池

- 默认每 120 秒扫描一次。主网和测试网均需有同名、正在交易的加密币 USDT 永续合约，标的类型必须是 `COIN`；排除股票等 TradFi 合约及 7 天内到期的合约。剔除 BTC/ETH，上市至少 30 天，24 小时名义成交额至少 2,000 万 USDT，24 小时高低价幅度在 2%～80% 之间，取波动和流动性评分前 8 个。
- 默认读取最近 120 根已收盘 5m K 线及 120 根已收盘 15m K 线，持续保存新增数据。币池随最新市场变化，不能把今天挑出的币池在过去的收益当成没有选择偏差的回测。
- 指标包括 EMA 8/21、RSI 14、ATR 14、MACD 柱、滚动 VWAP、5m/15m/1h 涨跌、相对成交量、波动率、15m 持仓量变化、主动买卖比、资金费和价差。另列 BTC 的短期市场背景。
- 三类模型：短期动量跟随、放量突破、趋势回撤后继续。评分 0～100 是规则评分，指标之间可能相关，分数不是胜率或盈利概率。
- 追价过远、5 分钟变化超过 4%、ATR 过高、RSI 极端、资金费对持仓方向过于昂贵或报价/持仓信息过期，都可以否决高分候选。

“跟风”在这里指跟随可观测的量价与订单流变化，不是加入喊单群或根据未经核实的社交热度买入。暂未建立新闻情绪、链上资金或机器学习训练管线；没有将这些缺失信息伪装成模型能力。

## 先复核再进入模拟

扫描器输出 `reports/tactical/signals.json`，包含快照 ID、指标时间、候选、分数和拒绝理由；不可变快照保存在 `snapshots/`。

本轮 Codex 读取这些信息，比较支持与反对证据，并写出一个候选 ID 或 `hold`（不交易）的判断。**不自动采用最高分，也不自动把规则评分冒充 AI 复核。** 本轮用户选择只复核一次，没有创建定期任务，也不会在后台调用语言模型。

复核文件有 90 秒有效期，只能使用一次，绑定当时的完整快照。执行前重新检查：

1. 指标不超过 180 秒，仍对应当前最新的完整 5 分钟 K 线；出现新 K 线需要新复核。
2. 主网/测试网报价及测试网盘口不超过 30 秒；价差不超过 20 bps。
3. 测试网标记价与主网偏离不超过 1%；价格相对复核时变化不超过 0.5% 或半个止损距离（二者取小）。
4. 交易所数量、步长、最小下单额有效，完整拟成交数量有可见深度，估计冲击不超过滑点假设。
5. 没有已有虚拟持仓，没有风险停机，也不在平仓后 5 分钟冷却期。

任一条件失败，本次判断就会记录为未执行，不重试旧判断。已持有的模拟仓位仍受风险退出管理。复核字段只是本地试验记录，不是实际交易账户授权。

## 更积极的预算与杠杆

| 参数 | 设定 |
| --- | --- |
| 每个独立对照场景的虚拟本金 | 50 USDT |
| 名义杠杆对照 | 1× / 2× / 3× |
| 初始保证金上限 | 本金的 60%，即约 30 USDT |
| 对应开仓名义金额上限 | 30 / 60 / 90 USDT，仍会被单笔风险约束进一步缩小 |
| 每笔预计止损风险，包含预计双边成本 | 最多 1 USDT |
| 日亏损停止新开仓 | 2.5 USDT，UTC 日切换 |
| 峰值回撤停止 | 20%，初始约 10 USDT |
| 用户最大损失容忍度 | 25 USDT，50% |
| 每边手续费 / 额外滑点假设 | 5 bps / 4 bps |
| 最长持有时间 | 120 分钟 |
| 初始止盈 | 初始止损距离的 2 倍 |

盈利达到一个初始风险距离后移动止损，只收紧不放宽。同一场景最多一笔持仓，不亏损加仓，不跨币种叠加。1×/2×/3× 是三份独立的 50 USDT 虚拟对照，不能把净值相加；实际总敞口也不一定等于名义杠杆。

保证金按名义金额除以杠杆近似预留，以固定 2% 维护保证金做风险压力检查；没有读取账户仓位档位。该模型不是币安实际强平算法，未精确建模保险基金、保证金档位、强平费用或穿仓处理。交易所会调整各币种档位，必须在真正接入账户前单独验证。跳空或断网后按重新观察到的价格模拟退出，损失可能超过止损线或用户容忍度，不能保证最多亏 25 USDT。

本模型还没有完成足够时长的历史和向前验证。一次正确方向或数分钟盈利，不能证明稳定正收益，更不能据此接管主网持仓。

## 使用

在项目根目录、`quant` 环境中：

```powershell
python -I scripts/tactical_lab.py scan
python -I scripts/tactical_lab.py status
```

复核时先阅读 `signals.json`，然后填写**实际看到的快照 ID 和候选 ID**。如果选择不交易，把候选 ID 换成 `hold`；不要直接复制占位符执行。

```powershell
python -I scripts/tactical_lab.py review --snapshot-id <快照ID> --candidate <候选ID或hold> --rationale "本轮具体依据、反对证据与决定"
python -I scripts/tactical_lab.py paper-once
```

持续采集和仓位管理使用两个独立进程，慢速币池扫描不会阻塞持仓观察：

```powershell
python -I scripts/tactical_lab.py scan-watch
# 另一终端
python -I scripts/tactical_lab.py paper-watch
```

`scan-watch` 不产生复核文件；`paper-watch` 没有新的有效复核就不会新开仓。不同 worker 有独立锁；同类 worker 运行时不能再执行其一次性命令。扫描和模拟均遇 HTTP 418/429 直接停止，其他请求错误退避。

停止两个短线 worker：在 `data/tactical/` 创建 `STOP` 文件。它不会停止原有 `data/lab/` 下的小时策略采集器。电脑必须保持运行和联网；模拟保护检查不是交易所服务器上的止损单。

## 结果文件

本地交互网页：运行 `python -I scripts/dashboard.py`，访问 http://127.0.0.1:8765。详见 [策略观测站](dashboard.md)。2026-09-15 用户已授权每 15 分钟 Codex 复核与新模拟开仓；原有单次复核限制已更新，所有风险和无真实订单边界保留。

- `tactical.toml`：公开参数。
- `reports/tactical/dashboard.html`：本轮判断和 1×/2×/3× 模拟净值。
- `reports/tactical/signals.json`：最新扫描证据。
- `reports/tactical/paper_status.json`：当前模拟状态、执行/拒绝理由和错误。
- `reports/tactical/decisions/` 与 `snapshots/`：本轮判断及其对应证据。
- `data/tactical/experiments/<实验ID>/state.json`：持久化账本、保证金、风险停机和已经消费的判断 ID。重启不会重复开仓或重置亏损。

这些数据和日志均被 Git 忽略，仓库只上传代码、公开模板、测试与说明。本次实现没有访问私人 dotenv 文件。

接口和时间语义依据 [Binance USD-M Market Data](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)：持仓量统计时间表示周期结束，主动买卖比时间表示周期开始，因此后者只有在整个周期结束后才用于判断。维护保证金档位会调整，例如 [2026-09-12 官方档位调整公告](https://www.binance.com/en/support/announcement/detail/2adc4f459022496db814a96b93215a1e)，不能把固定模拟参数当作账户实际参数。
