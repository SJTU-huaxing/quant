# 策略实验室：近期数据、逐币种策略与模型选币

本阶段实现公开行情采集、可复现回测和测试网行情上的持续模拟成交。**实验室没有交易所下单路径**，不读取账户、不使用 dotenv、不处理现有主网持仓。模拟盈利不是主网自动开通条件。

## 运行

在项目根目录的 `quant` 环境执行：

```powershell
conda activate quant
python -I scripts/strategy_lab.py bootstrap
python -I scripts/strategy_lab.py research
python -I scripts/strategy_lab.py watch
```

`bootstrap` 下载最近 180 天主网小时 K 线、资金费和交易规则，以及 20 天测试网数据。`research` 先刷新主网数据再比较策略。`watch` 读取冻结的研究结果，目标每 15 秒采集两张网络的最新报价、标记价格、指数价格、资金费率及持仓量，并补齐新收盘 K 线。REST 请求耗时会影响实际间隔；这是小时策略的准实时采集，不是逐笔或高频系统。

`once` 只运行一次采集和模拟。它会写入虚拟账户，适合检查运行，不适合用多次手动运行代替连续观察。首次 `watch` 前完成测试后，可在公开 `strategy.toml` 更换 `trial_id` 并重新 `research`，创建有独立审计记录的正式观察期。

不要同时启动多个采集器。程序通过 `data/lab/collector.lock` 防止重复 `watch`。`watch` 运行时不要执行 `bootstrap`、`research` 或 `once` 修改同一数据目录。

停止：

```powershell
New-Item -ItemType File -Path data/lab/STOP -Force
```

采集器在本轮请求结束后退出。重新启动前删除自己创建的 `STOP`；若崩溃留下 `collector.lock`，先核对其中的进程是否已退出，再删除锁。普通重启会恢复原有虚拟净值、风险停机状态和交易记录，不会把亏损清零。电脑休眠或网络断开会中断观察；恢复后存在报价间隔超过 30 秒的持仓先按当前报价模拟退出，本轮不重新开仓。

## 时间与新鲜度

- 存储统一采用交易所 UTC 毫秒时间戳。北京时间是 UTC+8；K 线边界按 UTC，日损失统计也按 UTC 日切换。
- 保存交易所报价时间、买卖价时间、标记价格时间、持仓量时间、交易所当前时间和本机接收时间。历史研究显示明确的起止时间，持续看板另列更新时间。
- 仅使用已经收盘且连续的 K 线。回测信号来自上一根收盘，最早在下一根开盘模拟执行；持续模拟在实际观察到的买卖价执行，启动时不补造过去的交易。
- 最新完整 K 线必须与交易所当前小时边界吻合；报价年龄必须在 0～30 秒。本机与交易所时间偏差超过 30 秒也暂停该轮新模拟信号；不会修改系统时间。
- 整点补 K 线后重新采集报价，避免将补历史数据之前的旧报价当成可成交报价。连续采集有超过 60 秒的间隔时，向前验证不能通过。
- 资金费按结算事件时间归属到当时持仓。延迟到达的结算会修正对应虚拟交易；换币不会把旧币种资金费错误扣到新币种。
- 看板超过 60 秒未更新会显示过期提示。不能把尚未收盘 K 线、陈旧快照或过去的研究结果称为当前实时结果。

## 两类实验

初始币池是 BTCUSDT、ETHUSDT、SOLUSDT 永续合约。其余币种尚未纳入验证，扩展币池需要交易规则、历史完整性、流动性与风险测试。

1. **逐交易对选策略**：趋势（12/48 均线）、40 根 K 线突破、24 根 K 线均值回归。三种固定策略分别测试每个币种；为每个币种仅根据验证期选策略。
2. **策略模型选交易对**：使用上述预先选定的每币种策略，对已收盘数据的趋势或偏离幅度减去预计成本，再除以波动率排名。信号为零、成本后得分非正、或下单门槛不满足时不入选；新币种得分须比当前持仓高 25% 才换币。共用**一个 50 USDT 虚拟账户、最多一个持仓**，换币扣除平旧仓和开新仓成本。

逐币种的 9 组试验各有独立虚拟本金，用于公平比较，净值不能相加，也不表示获准投入 450 USDT。选币组合有单独的一份 50 USDT 总账。模型是可解释的规则评分，不是已经训练出收益能力的机器学习模型。

市场风向目前包括均线方向、波动、价差、资金费、标记价相对指数的基差、持仓量变化及其实际观察间隔。尚未接入新闻或社交媒体情绪，指标不等于价格预测。

## 验证时间划分

默认最近 180 天中，最后 30 天作为预留测试集，紧邻之前的三个 21 天窗口作为验证集，其余较早数据提供策略预热背景。先按正收益验证窗口数排序，再按三个验证窗口的 1:2:3 近期权重评分。选择币种策略和选币模型参数时不读取预留测试集的结果。

此外展示最近 7 天独立重新起算的诊断，用于观察近期变化；它和最近 30 天结果有重叠，不能相加，也不参与本轮选优。不足默认历史长度的自定义配置会缩短窗口，并因样本不足阻止上线。

向前模拟期间冻结这些选择，使用新到来的行情。修改公开配置、`trial_id`、研究截止时间或引擎版本会生成不同实验标识。普通采集器重启读取已冻结研究文件，避免利用刚看到的行情重新选择过去的策略。重新研究后，旧数据仍保留在 SQLite 和 `reports/strategy_lab/experiments/<实验标识>/research.json`，不同试验的收益与观察天数不能拼接。

## 50 USDT 风险预算

| 约束 | 默认值 |
| --- | --- |
| 虚拟策略本金 | 50 USDT |
| 用户最大损失容忍度 | 25 USDT（50%） |
| 更早的累计回撤停机 | 净值峰值的 10%，初始对应约 5 USDT |
| 当日停止开仓 | 亏损 1 USDT |
| 单笔预计风险 | 不超过当前可用策略本金的 1%，初始约 0.5 USDT |
| 开仓名义敞口 | 不超过本金的 50%，初始 25 USDT；组合最多 1 个持仓 |
| 模拟手续费 / 滑点 | 每边 5 bps / 2 bps；另做双倍成本压力测试 |

止损距离由 ATR 决定，波动过大时跳过。数量按交易所步长向下取整，低于最小下单额直接跳过，不借助更高杠杆满足门槛。禁止马丁格尔与亏损加仓。25 USDT 是入场时敞口上限，持有期间名义金额会随价格变化。

手续费是研究假设，未读取账户费率或 VIP 等级。真实交易需要另行核实手续费、资金费、滑点、部分成交、服务器保护单、重启恢复和仓位对账。回测使用当前交易规则；不重建历史交易规则或强平过程。OHLC 无法还原根内价格路径，止损成交时间记为该根结束，可能同时发生止损与资金费时按不利顺序估计。**跳空、网络中断及成交偏差可能超过停机阈值；这些阈值不是最大损失保证。**

## 上线条件和当前边界

历史门槛包括足够的 180 天数据、完整资金费、三个验证窗口均为正、预留测试期至少 30 天及 30 笔平仓、扣成本净收益为正、利润因子至少 1.2、未触发风险停机，以及双倍成本后仍盈利且未触发风险停机。还需要至少 30 天连续向前验证和 30 笔已平仓，以及真实测试网策略执行和成交对账验证。门槛用于拒绝证据不足的策略，通过也不保证未来盈利。

本阶段 `mainnet_enabled` 始终为 false，实验室的公共客户端只能访问固定 GET 行情接口，没有主网交易适配器或自动平现有仓位的开关。组合模型尚需额外独立向前验证；单币种通过不能替代组合验证。未来处理现有主网订单之前，还必须核对其资金占用、保证金模式和独立的 50 USDT 分配，否则该预算无法约束已有仓位的风险。

按仓库 [AGENTS.md](../AGENTS.md)，代理不能通过 dotenv 或子进程加载私人配置。账户验证和真实测试网下单必须由用户在自己终端启动。旧 `testnet_execution` 是独立的连通性往返演示，不是本策略框架，也不能用它的结果证明策略盈利。当前实验室仅有模拟成交。

## 文件与接口

- `strategy.toml`：无秘密的实验设置。
- `src/quant_binance/lab/`：公共行情、虚拟账本、策略、选币组合、研究、采集与看板。
- `data/lab/market.sqlite3`：公开行情和虚拟交易状态，已被 Git 忽略。
- `reports/strategy_lab/dashboard.html`：30 秒自动刷新看板。
- `reports/strategy_lab/latest.json`：机器可读的最新市场、虚拟账户与未通过条件。
- `reports/strategy_lab/research.json`：本轮冻结的历史验证结果。

公开数据使用 [Binance USD-M REST Market Data](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data) 中的行情接口。传输采用普通 HTTPS、证书验证和 `trust_env=False`，遵循用户现有 OS/TUN 路由，不设置显式代理或改变系统网络。遇到 HTTP 418/429 停止采集，其他网络错误退避，异常输出仅含类型，不包含远端正文。

离线检查：

```powershell
python -m pytest tests
python -m ruff check src tests scripts
```

测试用假配置和内存数据，禁止网络访问，不打开任何私人 dotenv 文件。
